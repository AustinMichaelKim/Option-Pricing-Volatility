# Project Brief

## Title

Option Pricing and Volatility Analysis using Black-Scholes,
Monte Carlo Simulation, and Implied Volatility

## Objectives

1. Implement European option pricing using Black-Scholes.
2. Implement Monte Carlo pricing under geometric Brownian motion.
3. Compare analytical and simulation prices.
4. Recover implied volatility from market option prices.
5. Analyze volatility smile/skew using real option-chain data.

## Deliverables

- Reusable Python modules
- Unit tests
- Analysis notebooks
- Pricing and convergence figures
- Implied-volatility analysis
- Final report

## Initial scope

- European calls and puts
- Constant risk-free rate and volatility
- Continuous dividend yield where applicable
- Risk-neutral geometric Brownian motion

## Out of scope for the initial version

- American-option pricing
- Stochastic-volatility calibration
- Transaction-cost modeling
- High-frequency or production trading systems
