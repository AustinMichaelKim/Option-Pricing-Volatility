# Roadmap

## M1. Black-Scholes core

- Call and put pricing
- d1 and d2
- Put-call parity tests
- Boundary and numerical-stability tests

## M2. Greeks

- Delta, Gamma, Vega, Theta, Rho
- Analytical formulas
- Finite-difference validation

## M3. Monte Carlo

- Risk-neutral GBM simulation
- Discounted payoff estimation
- Standard error and confidence interval
- Convergence analysis

## M4. Implied volatility

- Root-finding implementation
- No-arbitrage price validation
- Failure handling
- Comparison across strikes and maturities

## M5. Market-data analysis

- Option-chain collection and cleaning
- Mid-price calculation
- Implied-volatility surface data
- Smile/skew visualizations

## M6. Final comparison and report

- Black-Scholes versus Monte Carlo
- Error and convergence discussion
- Market implied-volatility interpretation
